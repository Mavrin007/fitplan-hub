# AGENTS.md — KILO / fitplan-hub

Правила для агентов, работающих в этом проекте.

## Публикация изменений на GitHub — ОБЯЗАТЕЛЬНО после каждого крупного обновления

После каждого крупного обновления (новый фича-цикл, релиз, большой рефакторинг)
агент обязан опубликовать изменения в репозиторий `Mavrin007/fitplan-hub`.

Git-команды в песочнице заблокированы платформой («Vly manages version control»),
поэтому используется штатный скрипт `scripts/push-to-github.mjs` — он пушит через
GitHub Git Data API и сам исключает секреты/артефакты (`.env*`, node_modules, dist,
test-results, isolate, e2e-live и т.д.).

```bash
# из корня проекта; токен — из Keys/API keys платформы (GITHUB_TOKEN) или от пользователя
node scripts/push-to-github.mjs <GITHUB_TOKEN> "KILO vX.Y: краткое описание изменений"
```

### Порядок работы перед пушем (валидация)

1. `bun convex dev --once && bun tsc -b --noEmit` — кодген Convex + типы (если менялись файлы в `src/convex/`)
2. `bunx eslint <изменённые файлы>` — линт
3. `bun vitest run` — полный прогон тестов
4. При изменениях UI/флоу — `bunx playwright test <затронутые спеки>` — E2E

Только после зелёной валидации — push. Сообщение коммита:
`KILO vX.Y: <что сделано>` — кратко, по делу, без перечисления файлов.

### Токен

- Токен передаётся аргументом скрипту или через env `GITHUB_TOKEN`.
- Никогда не печатать токен целиком в выводе/чате — скрипт сам выводит только префикс.
- Не светить токены в переписке: пользователь держит их в Keys/API keys платформы.
